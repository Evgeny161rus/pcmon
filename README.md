# PC Monitor

**PC Monitor** показывает телеметрию Windows-ПК на сенсорном дисплее ESP32-S3. Проект состоит из прошивки платы и Python-агента для Windows. Связь по Wi-Fi поддерживает автообнаружение агента; для запуска агента с окном, значком в трее и USB-связью есть приложение-компаньон.

> Проект рассчитан на конкретную плату Freenove / LCDWIKI ES3C28P. Для других ESP32-S3 дисплей, тач, звук и периферию придётся адаптировать.

## Возможности

- Четыре страницы: обзор, графики, сеть и настройки.
- 12 экранных скинов: **Приборы, Неон, Минимализм, Ретро-радио, Часы, Терминал, Плитки, Лампы, Импульс, Шина, HUD, Сканлайн**.
- CPU, память, GPU, диски, сеть, Wi-Fi, пинг, аптайм и топ процессов. Температуры читаются из LibreHardwareMonitor, а температура NVIDIA GPU — также из `nvidia-smi`, если утилита установлена.
- Регулировка и mute системной громкости Windows с экрана.
- Проверка скорости сети с этапами и результатами загрузки, отдачи, пинга и джиттера.
- Автопоиск агента в локальной сети по UDP и настройка Wi-Fi платы через точку доступа с captive portal.
- Настраиваемые яркость, затемнение и звуковые клики; статусный WS2812, батарея и запись метрик CSV на microSD.
- Веб-панель агента и приложение-компаньон Windows.

## Плата и периферия

Проект настроен для **Freenove / LCDWIKI ES3C28P** на **ESP32-S3 N16R8** (16 МБ Flash, 8 МБ PSRAM), с цветным IPS-дисплеем 2,8″, разрешением 320×240 и ёмкостным тачскрином. В прошивке используются ILI9341, контроллер тача FT6336G, аудиокодек ES8311 с усилителем FM8002E, слот microSD, вход измерения батареи и RGB-светодиод WS2812.

Пины из `firmware/src/board.h`:

| Функция | Подключение ESP32-S3 |
|---|---|
| Дисплей ILI9341: SCK / MOSI / MISO | GPIO 12 / 11 / 13 |
| Дисплей: CS / DC / RST / подсветка | GPIO 10 / 46 / не подключён / 45 (PWM) |
| Тач FT6336G: SDA / SCL / INT / RST | GPIO 16 / 15 / 17 / 18, адрес I²C `0x38` |
| ES8311: MCLK / BCLK / LRCK / DOUT / DIN | GPIO 4 / 5 / 7 / 8 / 6 |
| Усилитель аудио | GPIO 1, активный LOW |
| microSD SDMMC: CLK / CMD / D0 | GPIO 38 / 40 / 39 (1-bit) |
| Измерение батареи | GPIO 9, коэффициент делителя 3.0 |
| WS2812 | GPIO 42 |

Пины и калибровка сенсора описаны в `firmware/src/board.h`. Перед использованием схемы сверяйтесь с маркировкой вашей ревизии платы.

## Структура

```text
firmware/src/     исходники прошивки и конфигурация платы
agent/            Python-агент, приложение Windows и список зависимостей
tools/             утилита подготовки шрифта
platformio.ini     конфигурация PlatformIO / Arduino
```

В прошивке `main.cpp` запускает устройство и Wi-Fi; `display.cpp` и `ui.cpp` отвечают за экран и интерфейс; `monitor.cpp` — обмен с агентом; `portal.cpp` — точка доступа и веб-настройка; `settings.cpp` хранит параметры в NVS. Отдельные модули управляют звуком, индикацией, картой памяти и тревогами.

Агент `agent/sysmon_agent.py` собирает данные с Windows, отдаёт REST API и принимает команды. `agent/pcmon_app.pyw` запускает его как приложение-компаньон с окном управления и системным треем.

## Обмен данными

- Агент рассылает UDP-маяк `PCMON1|ip|port|host` на порт **4210**. Плата отправляет `PCMON?` для поиска и запоминает найденный адрес.
- Экран получает метрики по HTTP с агента на порту **8123**.
- USB CDC может использоваться приложением-компаньоном для обмена настройками/данными, если плата подключена USB-кабелем к ПК.
- Основные API агента: `GET /api/stats`, `GET/POST /api/volume`, `GET/POST /api/speedtest`, `GET /api/health`. Веб-панель доступна по `http://127.0.0.1:8123/` на ПК.

Для автообнаружения плата и ПК должны быть доступны в одной локальной сети. В брандмауэре Windows может потребоваться разрешить входящие TCP-подключения на 8123 и UDP-пакеты на 4210 в профиле частной сети.

**Безопасность:** HTTP API агента не требует пароля и отдаёт системную телеметрию, а также принимает команды громкости и теста сети. Запускайте агент в доверенной локальной сети и ограничивайте правило брандмауэра частной сетью. Не публикуйте порт агента напрямую в интернет.

## Требования

- Python 3.10+ для агента Windows.
- PlatformIO Core для сборки и загрузки прошивки; зависимости библиотек PlatformIO указаны в `platformio.ini`.
- Windows 10/11 для функций агента, использующих системные счётчики, WLAN и pycaw.
- `nvidia-smi` (опционально) для данных GPU NVIDIA; LibreHardwareMonitor (опционально) для температур CPU/GPU.
- microSD (опционально) для локального CSV-журнала.

## Установка и запуск агента

Откройте PowerShell в папке проекта:

```powershell
cd agent
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python sysmon_agent.py
```

Для приложения-компаньона установите те же зависимости и запустите `pythonw .\pcmon_app.pyw` или используйте `python .\pcmon_app.pyw`. При первом запуске Windows Firewall может показать запрос доступа к частной сети. Для температур через LibreHardwareMonitor включите его веб-сервер и укажите URL, например:

```powershell
python sysmon_agent.py --lhm http://127.0.0.1:8085/data.json
```

Ключи агента можно посмотреть через `python sysmon_agent.py --help`. USB-порт при необходимости задаётся аргументом `--usb-port COMx` или переменной `PCMON_USB_PORT`.

## Сборка и прошивка

Установите PlatformIO Core в используемое окружение Python и из корня репозитория выполните:

```powershell
python -m platformio run
python -m platformio run -t upload --upload-port COMx
python -m platformio device monitor --port COMx --baud 115200
```

Замените `COMx` на порт платы из диспетчера устройств. Закройте приложение/агент, если он занимает последовательный порт. В `platformio.ini` задан `build_dir` вне папки проекта, чтобы избежать известной проблемы GNU linker с кириллическими путями в некоторых Windows-сборках. Если путь `C:\pio\pcmon` неудобен, поменяйте `build_dir` на доступную папку, в пути которой только латинские символы. Сам проект также можно клонировать в путь без кириллицы, например `C:\src\pcmon`.

Профиль PlatformIO использует `esp32-s3-devkitc-1`, Arduino framework, QIO Flash / OPI PSRAM и таблицу разделов на 16 МБ. Эти параметры выбраны под ES3C28P и могут не подойти другой плате.

## Первая настройка платы

1. Подайте питание на плату. Если Wi-Fi ещё не настроен, появится точка доступа `PCMonitor-XXXX`.
2. Подключитесь к ней с телефона или ПК. Заводской пароль точки доступа — `12345678`.
3. Откройте `http://192.168.4.1/`, выберите домашний Wi-Fi и сохраните настройки.
4. Подключите плату и компьютер с агентом к одной сети и запустите агент или приложение-компаньон.
5. При исправной локальной сети плата обнаружит агент автоматически. Адрес также можно задать вручную в меню «Ещё».

Заводской пароль точки доступа фиксирован в прошивке и предназначен для первичной настройки. Он не является индивидуальным секретом; рядом с недоверенными людьми держите точку доступа выключенной. Wi-Fi-пароль платы сохраняется локально в NVS и в репозиторий не записывается.

## Погода и персональные настройки

В проекте есть поиск российских городов для прогноза погоды. Конфигурация агента `agent/city.json` создаётся локально при выборе города и намеренно исключена из Git. Для своего устройства выберите город через приложение-компаньон. Позывной/подпись скина «Ретро-радио» задаётся через настройки; личные значения не включены в репозиторий.

## Скины

Скины — отдельные от палитры меню варианты главного экрана. Их реализация находится в `firmware/src/skins.cpp`, а общие цветовые темы интерфейса — в `firmware/src/ui.cpp`. Добавляя скин, обновите число и названия также в агенте, чтобы список в приложении-компаньоне совпадал с прошивкой.

## Разработка

Исходники содержат поддержку специфичных для этой платы пинов и требуют проверки на целевом устройстве при изменении драйверов, LVGL или конфигурации памяти. Сборка PlatformIO проверяет компиляцию, но работу сенсора, Wi-Fi, звука, microSD и USB нужно проверять на самой плате.
